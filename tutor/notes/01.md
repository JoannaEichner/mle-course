## What the learner should own after this module

- Names point at objects. Mutating through one name is visible through every other name; a mutable default argument is shared between calls.
- Pick the collection by the question: list for order, dict for lookup by key, set for membership and uniqueness, tuple for a fixed record.
- A comprehension builds a new collection from an old one; `if v is not None` and `if v` are different filters.
- A generator produces values on demand and can be consumed once.
- Files are opened with `with`, an explicit encoding and `pathlib.Path`.
- Exceptions: catch the narrow type, re-raise with a message that shows the bad input, never a bare `except:`.

Entry level: variables, loops, functions, lists, dicts. Anything beyond that (classes, typing, pandas) comes later. If the learner asks about pandas, say it arrives in module 06 and that this lab shows what it does underneath.

## Facts about the data worth having at hand

- Monash Car Parts, `data/raw/car_parts_dataset_with_missing_values.tsf`: 2,674 monthly series, 51 values each, January 1998 to March 2002, 345 kB.
- 4.5% of cells are `?`. 2,509 series have no missing month.
- 74.8% of known months are zero. Every series sells at least once; the largest total is 89 units (four series tie at 89: T2671-T2674).
- ADI above 1.32 ("intermittent") covers 2,671 series; only 3 are regular. Many series have ADI 51: one sale in 51 months.
- Header lines start with `@`, comments with `#`. The data starts after the `@data` line.

## Tasks

### 01.1 `parse_value`

- `if text == "?"` before `strip()`: fails for `" ? "`. The check does not feed that; do not push it, but ask what the file would do with a trailing newline.
- `int(text)`: fails for `"2.5"`. The check says so.
- Bare `except:` or `except Exception`. Ask: "Which errors do you expect here, and which ones would you rather see?"
- Returning `None` for garbage instead of raising. Ask how they would tell a missing month from a broken file afterwards.

### 01.2 `parse_series_line`

- `split(":")` without the limit. Works on this file; ask what happens if a name ever contains a colon. Do not insist.
- Returning a list. The check asks for a tuple; the lecture's "which collection" section is the place to send them.
- Keeping the time part of the date (`1998-01-01 00-00-00`).
- `line.split(":")` on a line with `\n` at the end: the last value becomes `"1\n"`. `float` tolerates it, so it passes. Point at `strip()` anyway.

### 01.3 `read_series`

- Building a list and returning it. The check says "ma być generatorem". Ask what `read_series(path)` returns before any line is read.
- `open(path)` without `with` or without `encoding`. Passes the check. Ask what happens to the file when the loop stops at the first series, and on which system the default encoding is not UTF-8.
- Not skipping blank lines: `parse_series_line("")` raises. The check's sample has one.
- Consuming the generator twice (`list(gen)` then iterate again) in 01.3b: the second pass is empty. A good moment for the lecture's generator section.

### 01.4 `demand_stats`

- `if v` instead of `if v is not None`: zeros disappear from the known months. The check catches it through `months` and `zero_share`.
- `ZeroDivisionError` on the all-missing or all-zero series. The check names the case; ask what the honest answer is when there is nothing to divide.
- ADI as `total / nonzero` or `nonzero / months`. Ask them to compute ADI for `[0, 0, 5, 0, 0, 5]` by hand and say it in words ("a sale every ... months").
- 01.4b: averaging the per-series `zero_share` values instead of dividing total zero months by total known months. The text warns against it; the two numbers differ because series have different numbers of known months. Ask what weight a series with 12 known months gets compared with one with 51.

### 01.5 `top_series`

- `sorted(..., reverse=True)` on `(value, name)`: ties come out by name descending. The check has a tie. Ask what `reverse` does to the second key.
- Sorting `stats.items()` and then filtering `None` inside the key: `-None` raises `TypeError`.
- Deleting `None` entries from the input dict. The check reports that the input changed.

### 01.6 `save_summary`

- `open(path, "w")` on a missing folder: `FileNotFoundError`. Lead to `mkdir(parents=True, exist_ok=True)`.
- Returning nothing. The check says the path is expected.
- `json.dump` with a file handle is fine too.

## The questions in 01.7

Discuss, do not grade.

1. **Regular versus intermittent.** Nearly everything is intermittent (2,671 of 2,674). The point is that the usual "average demand" picture does not fit this data.
2. **"Same as last month".** The question now names the metric in words (average absolute error in units, no formula); MAE itself is not introduced before lab 03. For intermittent series the previous month is usually zero, so the forecast is mostly zero. A metric that averages absolute errors over many zero months looks good; the warehouse still runs out every time a sale happens. Lead-in to module 05 (metrics) and 09 (censored demand); do not explain those modules here.
